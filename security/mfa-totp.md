# Standard TOTP / One-time passwords

I use Authy for (almost all of) my MFA/2FA accounts and the app is on my phone, ipad, work mac, and home mac.

Features:

- Syncs tokens/accounts across devices
- Copy-n-paste code from the app (vs. typing in)
- Relatively quick and easy to use
- Backup/encryption password (setting up on new system)

Drawbacks:

- No longer able to load app on macOS
- No app for Linux
