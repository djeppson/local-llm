# General Setup

- projects directory: `mkdir ~/projects`

## git

- linux: `sudo apt install git` | `pamac install git`
- mac: `git` at terminal to prompt installation

## Homebrew

- install [Homebrew](https://brew.sh/)

```
brew install gcc
brew install awscli
brew install aws-sam-cli
brew tap cargo-lambda/cargo-lambda
brew install cargo-lambda

brew install --cask font-bitstream-vera
brew install starship
```

## Consider:

```
brew install python@3.11  # <-- confirm version
brew install codium
```
